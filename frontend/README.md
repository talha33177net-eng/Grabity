# Grabity frontend

React storefront and admin panel for Grabity. See the [main README](../README.md) for setup, configuration and
deployment.

- `npm run dev`: dev server on http://localhost:5173 (expects the API on http://localhost:5080)
- `npm run build`: type-checks and builds into `../backend/Grabity.Api/wwwroot`
- `npm run lint`: oxlint
